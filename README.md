# TEP Copilot (working title)

**A control-room copilot that collapses alarm floods into one verified root-cause card — and proves it reasons about the plant instead of reciting the textbook.**

Built for the AMD Developer Hackathon ACT III (lablab.ai), *Intelligent Industry* challenge.
Gemma 4 served with vLLM on a single AMD Instinct MI300X (ROCm), with Evolus business workflows.

> Status: pre-kickoff scaffold. Every number in this README will be generated by `scripts/verify_claims.py`
> from pinned data in `data/` — nothing here is claimed yet.

## Invariant
Statistics detect → the LLM proposes → a deterministic gate verifies → a human approves.
The model has no write access to the process and cannot issue control actions.

## Data
- Tennessee Eastman Process, Rieth et al. (2017), Harvard Dataverse, doi:10.7910/DVN/6C3JR1 (public domain).
- Baseline: FaultExplainer (Khan et al., 2025), MIT license.

## Run

cp .env.example .env
